# Job description fixtures (ATS acceptance test)

Real-style job descriptions for `tests/test_ats_acceptance.py` and `scripts/manual_ats_test.py`.
Each file is `{"title", "company", "kind", "text"}`. They are written in the shape and vocabulary of
public postings for each role family (backend, ML/LLM, full-stack, data, infra, mobile, security);
company names are fictional and no text is copied from a private source. Add a file to add a case.
